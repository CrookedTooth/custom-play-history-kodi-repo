# Test material

`test_silvo_integration.py` is the guarded-patcher regression test. It requires a locally obtained, verified stock Aeon Nox: SiLVO 10.0.3 fixture. The third-party skin archive and extracted stock XML are deliberately excluded from this public repository.

The fixture provenance and SHA-256 values are documented in the local development record. Obtain the stock package from Kodi’s official Omega add-on distribution before running the test.
